# Case notes (optional, but makes articles much stronger)

Drop a short note here whenever you have a real example the writer agent may use.
Name the file after the topic, e.g. `llm-agent-fraud-analytics.md`.

Write 5–10 plain lines:

- **Situation:** what the organisation was facing
- **Task:** what you were asked to fix
- **Action:** what you actually did (tools, process, team)
- **Result:** numbers you are comfortable publishing
- **Can I name the company?** yes / no

The writer agent will ONLY use personal results from these notes and `profile.yaml`.
It never invents results for you. Without a note, it uses published industry case studies (with sources).
